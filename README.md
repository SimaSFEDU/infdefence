# ∞ Оборона — исходники (v6.3.2)

- `index.html` — вся игра: HTML, CSS и JavaScript в одном файле. Открывается в любом браузере.
- `android/` — обёртка для Android: WebView, который показывает index.html.
  - `src/.../MainActivity.java` — экран игры, полноэкранный режим, кнопка «назад», вырез камеры.
  - `src/.../GameStore.java` — сохранения (SharedPreferences), вибрация, копирование в буфер.
  - `AndroidManifest.xml` — версия 6.3.2 (versionCode 16), разрешение на вибрацию.
  - `res/` — иконка и название приложения.
- `signing/key.jks` — ключ подписи (alias `td`, пароль `tdpass1`). Новые версии нужно подписывать
  этим же ключом, иначе Android не даст поставить их поверх старой без удаления (и сохранения пропадут).
  Не выкладывай его в открытый доступ.
- `build.sh` — сборка APK без Android Studio.

Чтобы изменить игру, достаточно править `index.html`; для APK потом запусти `build.sh`.
